# Event Registration System

A full-stack Event Registration System developed to simplify event management and participant registration. The system allows users to view available events, register for events, and manage their registrations. Administrators can create and manage events through an admin dashboard.

## 🚀 Features

### User Features
- User registration and login
- View available events
- Register for events
- Cancel registrations
- View registered events

### Admin Features
- Admin login
- Create new events
- Manage events
- View registrations
- Control event details

## 🛠️ Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- bcrypt.js

### Mobile
- Flutter (Mobile Application Development)
