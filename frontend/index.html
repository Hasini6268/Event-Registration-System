About EventSphere

EventSphere is a web-based Event Registration System developed as a mini project using HTML, CSS, JavaScript, Node.js, Express.js, MongoDB, and JWT Authentication.

The platform enables students to register securely, browse events, participate in technical and cultural activities, manage their registrations, and provides administrators with tools to create, update, and manage events efficiently.
